# Module 02 – Prompt Engineering & AI Productivity

**Program:** Codomax Digital Solutions  
**Level:** Beginner  
**Duration:** Day 6 – Day 10

## Overview

This repository contains the practical exercises and final project completed as part of Module 02 – Prompt Engineering & AI Productivity.

The module focuses on developing effective prompts, generating structured outputs, using AI for software development tasks, and building reusable AI productivity workflows.

## Learning Objectives

- Understand zero-shot, one-shot, and few-shot prompting.
- Apply roles, context, instructions, and constraints.
- Generate structured outputs such as JSON.
- Use AI for summarization, classification, and content generation.
- Explore AI-assisted coding, debugging, and code review.
- Create reusable prompt templates.
- Build a basic AI Productivity Toolkit using Python.

## Final Project – AI Productivity Toolkit

A Python-based collection of reusable prompt workflows designed to support common productivity tasks:

1. Text summarization
2. Business email writing
3. C# coding assistance
4. Research assistance

The toolkit uses Python functions and reusable prompt templates to generate structured instructions for AI tools.

**Note:** The toolkit generates prompts; it does not directly call an external AI model.
